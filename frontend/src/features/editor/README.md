# features/editor — ③ 장면 확인·수정 (FR-03)

- `SceneList.tsx`: 장면 확인 카드. 대본 요약, 예상 길이(목표 30~60초), 장면 목록, 장면 추가(CTA 앞 점선 카드), 음성과 음악 설정, "영상 만들기" 버튼
- `SceneStrip.tsx`: 자막 카드를 가로로 늘어놓은 목록. 마우스로 카드 빈 곳이나 썸네일을 잡고 끌면 좌우로 넘김(조금이라도 끌면 클릭으로 치지 않음)
- `SubtitleCard.tsx`: 자막 하나를 카드 하나로 표시. 같은 장면의 카드는 이미지를 같이 쓰고 `1/3`처럼 순서를 표시. 장면 설정(화면 제목, 움직임)은 장면 첫 카드에만 둠. 중간 카드에서 이미지를 바꾸면 그 자막부터 새 장면이 되고, 앞뒤 장면과 이미지가 같아지면 다시 합쳐짐(`pipelineReducer.ts`의 `setSceneImage`)
- `useSceneReorder.ts`: 장면 머리의 ⠿ 손잡이로 순서 바꾸기. 장면에 속한 카드가 함께 움직임. 마우스·터치는 끌어서 놓고(놓을 자리는 초록 선, 가장자리에서는 자동으로 넘김, Esc로 취소), 키보드는 손잡이에서 ←/→
- `SceneMenu.tsx`: 카드 머리의 ⋮ 메뉴 — 원문 위치 보기, 이 자막 삭제, 장면 앞뒤 이동, 장면 삭제. 화살표·Home·End·Esc로 조작
- `ImagePicker.tsx`: 블로그 이미지 / 내 컴퓨터 이미지(브라우저 임시 주소) / 이미지 없음 선택
- 장면 상태는 서버에 저장하지 않고 `features/pipeline/pipelineReducer.ts`에서 관리 (docs/architecture.md 2절)
