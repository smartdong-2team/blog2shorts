# 배경음악 음원

| 파일 이름 (`.mp3`, `.m4a`, `.wav`) | 화면 표시 |
| ---------------------------------- | ----------------- |
| `soft_piano`                       | 잔잔한 피아노     |
| `light_acoustic`                   | 경쾌한 어쿠스틱   |
| `dreamy_synth`                     | 몽환적인 신스     |

음원을 저장소에 커밋하기 전에 재배포 가능 여부를 확인하세요.
